# Fixtures sintéticas

Páginas **escritas à mão** com a forma de JSON-LD e Open Graph que as lojas
costumam publicar. Testam o parser e as regras; **não** provam que uma loja
funciona. Isso só se sabe com o smoke com links reais (`tool/import/README.md`).
Quando houver respostas reais autorizadas, guardam-se aqui com o nome da loja e
a data.
